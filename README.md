# 灰度轨

中文名：**灰度轨** · 前缀 `flagrail` · 端口 **6800 / 11800**

## 骨架

**开关版本入轨 → 分桶灰度下发 → 回读确认 → 失效/回滚互证**

皮：功能开关 / 配置灰度控制台。去皮是 **版本入轨 + 分桶下发 + 回读确认 + 命运互证**，不是配置 CRUD、不是 RBAC、不是发版审批闸。

领域：**基础设施** · 子方向：**中间件**

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6800
# 开关轨 → 入轨样例 → 分桶规 → 下发 → 回读样例 → 轨贯验 → 回滚样例
```
